Keys are stored only on your device — never sent to a third party.
Privacy: All requests go directly from your device to api.polymarket.us — nothing passes through any server.
Note on signing: Polymarket US requires Ed25519 request signing which can block direct browser calls. If sync fails, use the Python export guide to pull your data and paste it in.
